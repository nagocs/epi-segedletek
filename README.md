# Eszközhasználati segédlet elsőéves gépészhallgatóknak

Kiegészítés az **Egy jó házi feladat rejtelmei** előadáshoz, BME GPK hallgatóknak.

A segédlet célja, hogy segítsen a házi feladatokhoz használható dokumentációs és számítási eszközök telepítésében és első önálló használatában. Az adott tantárgy kiírása határozza meg a beadás, az önálló munka és az eszközhasználat követelményeit.

Az előadást külön kapják meg a hallgatók. Ez a repó eszközhasználati kiegészítés; konkrét házifeladat-megoldásokat és dokumentumsablonokat nem tartalmaz.

## Merre induljak?

Ha most látsz először GitHub-oldalt, kezdd a [letöltéssel és a mappák megismerésével](docs/kezdes.md). Az útmutatók olvasásához nem kell programozói előismeret.

| Ezt szeretném | Itt kezdjem |
| --- | --- |
| Átgondolni a házim elkészítését | [Rövid általános útmutató](docs/hazi-feladatok.md) |
| Eldönteni, melyik eszközt használjam | [Eszközválasztás](docs/eszkozvalasztas.md) |
| LaTeX-et kipróbálni telepítés nélkül | [Overleaf](docs/latex/overleaf.md) |
| LaTeX-et használni a saját gépemen | [Windows + VS Code](docs/latex/vscode-windows.md) · [macOS/Linux](docs/latex/macos-linux.md) |
| Pythonban számolni | [Windows + VS Code](docs/python/vscode-windows.md) · [macOS/Linux](docs/python/macos-linux.md) |
| Mathematicát használni hallgatói licenccel | [Licenc és telepítés](docs/mathematica/bme-licenc-es-telepites.md) |
| Egy konkrét műveletet kipróbálni | [A négy eszközbemutató példa](peldak/README.md) |
| Ellenőrizni a beadás előtt | [Ellenőrzőlista](docs/ellenorzolista.md) |

**Egyszerre egy útvonalon haladj.** Dokumentumkészítéshez választhatsz Overleafet vagy helyi LaTeX-et; számításhoz kezdetben elég a Python vagy a Mathematica egyikét megismerni. A példák mindkét számítási környezetben ugyanazokat a műveleteket mutatják be.
