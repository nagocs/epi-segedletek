# LaTeX: telepítés és első lépések

[Kezdőlap](../../README.md)

A LaTeX szöveges forrásból készít formázott dokumentumot. A `.tex` fájlt írod, a fordító PDF-et állít elő. A fordítás nem végez matematikai számítást: a beírt képletet szedi ki.

## Válassz útvonalat

1. **[Overleaf](overleaf.md):** böngészőben használható, nem kell saját TeX-telepítés. Első próbához ez a legrövidebb út.
2. **[Windows + VS Code](vscode-windows.md):** saját gépen telepített fordítóval dolgozol.
3. **[macOS/Linux + VS Code](macos-linux.md):** rendszerhez igazított telepítési lépések.

Utána mindhárom esetben: [első fordítás](elso-forditas.md) → [alapműveletek](alapmuveletek.md). Elakadás esetén: [hibakeresés](hibakereses.md).

Az útmutatóban magyarázott kódrészletek vannak. A saját próbafájlodat te hozod létre; nincs letölthető dokumentumsablon vagy kitöltendő címlap.
