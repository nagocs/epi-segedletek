# Fogalomtár

[Kezdőlap](../README.md)

| Fogalom | Jelentés ebben a segédletben |
| --- | --- |
| Repó / repository | A projekt fájljainak és változásainak gyűjteménye. |
| Git / GitHub | A Git változáskövető program; a GitHub a repó online elérési helye. |
| README / Markdown | Magyarázó oldal / egyszerű, szöveges formátum, amelyből a GitHub formázott oldalt jelenít meg. |
| Projektgyökér | A letöltött projekt főmappája, benne a `requirements.txt` fájllal. |
| Kiterjesztés | A fájlnév vége, például `.py`, `.nb`, `.tex` vagy `.pdf`. |
| VS Code | Szerkesztő: fájlokat írhatsz és megnyithatsz benne. |
| Bővítmény / extension | A szerkesztő képességeit kiegészítő eszköz. Nem feltétlenül tartalmazza a futtatóprogramot. |
| Terminál | Panel, amelyben parancsokat adsz a parancsértelmezőnek, például PowerShellnek. |
| Interpreter | A Python-kódot végrehajtó program. |
| Virtuális környezet / `.venv` | A projekt saját Python-környezete, külön telepített csomagokkal. |
| `pip` | Python-csomagok telepítője; a `python -m pip` a kiválasztott Pythonhoz tartozót indítja. |
| Kernel | A notebook számításait végző folyamat; megjegyezheti korábbi változók értékét. |
| Cella | Egy notebook külön szerkeszthető szöveg- vagy kódrészlete. |
| Fordítás / compile | A LaTeX-forrás feldolgozása, amelynek eredménye PDF lehet. |
| TeX-disztribúció | A fordítót és csomagokat tartalmazó telepítés, például TeX Live vagy MiKTeX. |
| Preambulum | A LaTeX-forrás `\begin{document}` előtti része; ide kerülnek a csomagok és beállítások. |
| PATH | Azoknak a mappáknak a listája, amelyekben a rendszer a parancsként indított programokat keresi. |
| Relatív útvonal | Egy adott mappához viszonyított fájlhely, például `abrak/grafikon.pdf`. |
| Egzakt / közelítő | Pontos matematikai alak / véges pontosságú érték. |
| Maradék | Az egyenlet bal és jobb oldalának különbsége egy behelyettesítés után. |

Következő lépés: [első Python-program](python/elso-program.md) vagy [első LaTeX-fordítás](latex/elso-forditas.md).
